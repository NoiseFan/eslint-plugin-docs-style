# Padding around custom container

规范 VitePress 自定义容器与外部内容之间，以及容器边界与内部内容之间的空行。

## 规则详情

### 普通容器

当自定义容器前后存在同一层级的内容时，容器标记与外部内容之间必须且只能有一个空行：

- 容器起始标记前保留一个空行
- 容器结束标记后保留一个空行
- 多余的连续空行会被压缩为一个空行
- 位于文件开头的容器前、位于文件结尾的容器后不强制添加空行

容器内部不允许在边界处出现空行。起始标记的下一行和结束标记的上一行必须是内容或另一个容器标记；如果存在空行，会被删除。

该规则的**正确**示例：

```md
::: info
内容一
:::

::: tip
内容二
:::
```

该规则的**错误**示例：

```md

::: info

内容

:::


其他内容
```

上例中，容器内部的空行会被删除，容器外部多余的空行会被压缩为一个空行。

### 嵌套容器

嵌套容器按照相同规则分别处理。相邻的外层与内层起始标记之间，以及相邻的内层与外层结束标记之间不留空行，以优先满足容器边界内侧不得为空行的约束：

- 内层容器的起始标记前保留一个空行
- 内层容器的结束标记后，如果还有外层内容，则保留一个空行
- 内层容器起始标记的下一行不能为空，结束标记的上一行也不能为空
- 外层容器的结束标记与外层最后一段内容之间不能有空行

例如，下面的嵌套结构是正确的。内层容器前后各有一个空行，外层最后一段内容与外层结束标记直接相邻：

```md
::: info
This is an info box.

::: tip
This is a tip box.
:::

This is an info box.
:::
```

下面的嵌套结构不正确：

```md
::: info
This is an info box.


::: tip

This is a tip box.

:::


This is an info box.

:::
```

修复后，内层容器前后的连续空行会各压缩为一个，内层容器边界处的空行和外层结束标记前的空行会被删除。

该规则支持自动修复。

## 不适用场景

如果项目不使用 VitePress 自定义容器，或者不希望统一容器与周围内容之间的空行，可以关闭这条规则。
