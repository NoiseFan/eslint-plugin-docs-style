# Valid heading anchor

要求包含非英文字母的 Markdown 标题声明明确且稳定的锚点。

## 规则详情

此规则检查源码中至少包含一个 Unicode `Han` 字符的 Markdown 标题节点（即非英文字母字符）。这类标题必须声明一个与标题文本以空白分隔的严格锚点，格式为 `{#lowercase-anchor}`。

严格锚点可以包含小写 ASCII 字母和数字，单词之间必须使用单个连字符分隔。大写字母、下划线、连续连字符、开头或结尾的连字符，以及非 ASCII 字符均不符合要求。

不包含 Unicode `Han` 字符的标题无需声明显式锚点。

## 选项

此规则没有选项。

## 正确示例

标题只包含英文字母，不需要显式锚点：

```md
# Introduction
```

锚点使用小写 ASCII 字母，且与标题文本之间有空格分隔：

```md
# 简介 {#intro}
```

锚点由小写 ASCII 字母组成，格式符合 `{#lowercase-anchor}`：

```md
# 中文标题 {#chinese-title}
```

锚点可以包含数字，并使用单个连字符分隔单词：

```md
# 标题 {#section-2}
```

## 错误示例

标题包含非英文字母，但末尾没有锚点：

```md
# 中文标题
# 你的第一个测试 Your First Test
```

锚点包含大写字母，必须全部使用小写：

```md
# 中文标题 {#Chinese-Title}
```

锚点包含连续连字符，单词之间只能使用一个连字符：

```md
# 中文标题 {#chinese--title}
```

锚点包含非 ASCII 字符，锚点内容只能使用小写 ASCII 字母和数字：

```md
# 中文标题 {#中文标题}
```

## 自动修复

只有当标题末尾存在可被规范化的类似锚点片段时，此规则才能自动修复。修复器会将 ASCII 字母转换为小写，将空白和句点转换为连字符，删除其他不支持的字符，移除开头和结尾的连字符，并将该片段改写为带花括号的锚点。

标题末尾的松散锚点会被转换为带花括号的标准锚点：

修复前：

```md
# Vitest 3.2 发布了！ # Vitest 3.2 is out!
```

修复后：

```md
# Vitest 3.2 发布了！ {#vitest-3-2-is-out}
```

标题末尾包含行内代码时，修复器会移除代码标记并规范化锚点文本：

修复前：

```md
## 使用 `describe` 编组测试 #Grouping Tests with `describe`
```

修复后：

```md
## 使用 `describe` 编组测试 {#grouping-tests-with-describe}
```

已有锚点但包含大写字母时，修复器会将其转换为小写：

修复前：

```md
# 中文标题 {#Chinese-Title}
```

修复后：

```md
# 中文标题 {#chinese-title}
```

如果标题末尾没有类似锚点的片段，规则只会报告问题，不会进行修复，因为它不会根据标题文本自行生成锚点。

修复器目前会保留下划线，但严格校验并不接受下划线。因此，包含下划线的类似锚点片段在自动修复后仍可能被报告。

## 忽略场景

此规则会跳过 YAML frontmatter 和不包含 Unicode `Han` 字符的标题。它只访问 Markdown 标题节点，因此不会检查标题以外形似标题的文本。

## 不适用场景

如果文档系统会自动生成锚点、不要求包含非英文字母的标题声明显式锚点，或者接受的锚点语法与此规则的严格格式不同，请关闭此规则。
